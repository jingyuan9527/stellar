# Stellar 功能发展方向（产品功能点）

> 定位：个人知识 / 实验沉淀池。游客可浏览落地页与关于我、体验工具；管理功能登录后可见。
> 本清单聚焦**产品功能方向**（未来可加的特性），非代码优化项。每条锚定现有模块延展，给 AI 程序员方向级实现指引。
> 已确认现状缺口：无博客发布、无双向链接/图谱、无智能体编排、无播客、无 RSS 通用摄入、无全局 AI 搜索。

---

## 一、知识沉淀深化（Memos / 知识库 / RAG）

### F1 — 笔记双向链接 + 知识图谱
- **痛点**：Memos 当前是单条笔记 + 标签，笔记之间孤立，"实验沉淀"无法连成网络。
- **基于**：现有 `memos_note`（content/tags/uid）、AI 打标签能力、`ai_knowledge_chunk` 向量检索基础设施。
- **方向**：笔记正文支持 `[[标题]]` 语法解析出链接关系，存 `memos_link` 表；前端加关系图谱（力导向图，ECharts/cytoscape）；点击节点跳关联笔记。可复用现有向量检索做"相似笔记"推荐。

### F2 — 知识库自动摄入（RSS / 邮件 / 网页剪藏）
- **痛点**：知识库手动上传，信息源分散。
- **基于**：现有 `AiKnowledgeService` + `MemosWebhookConfigDTO` 的 webhook 签名验证模式。
- **方向**：加 RSS 订阅源管理（定时拉取解析）、网页 URL 剪藏（抓取正文清洗入库）、邮件转发摄入（IMAP 监听或转发地址）；统一走现有知识库切片 + 向量化管线。

### F3 — 多模态记忆（图 / 音记忆）
- **痛点**：`AiMemoryService` 记忆当前仅文本，无法沉淀图片/音频片段。
- **基于**：现有记忆表结构、`sys_file` 文件存储、向量库。
- **方向**：记忆支持附图/附音；RAG 检索时多模态匹配（CLIP 类 embedding 或文本侧描述检索）；海螺/对话中可引用记忆里的图。

### F4 — AI 续写 / 润色 / 内联辅助写作
- **痛点**：写 Memos / 文章时缺少在输入框内联的 AI 帮手。
- **基于**：现有 `AiChatService` 流式能力、`/ai/chat` 接口。
- **方向**：Memos 编辑框加"选中文字 → 续写/润色/翻译/总结"浮层，复用流式 SSE；结果可直接插入正文。

## 二、AI 能力产品化

### F5 — 智能体编排 / 工作流（Agent Workflow）
- **痛点**：聊天、工具调用、知识库、人设各自独立，无法串成可复用自动化。
- **基于**：现有人设（`AiPersona`）、知识库、工具调用（`AiChatToolService`）、模板（`AiTemplate`）。
- **方向**：可视化编排节点（触发 → 取知识库 → 调 LLM → 调工具 → 落库/通知），存 `ai_workflow` 表；支持手动触发 / 定时 / webhook 触发；执行过程与结果可回看。这是把现有 AI 积木拼成"个人自动化"的关键一步。

### F6 — AI 文生图画廊 + 提示词模板库
- **痛点**：图片生成产物存 `sys_file` 但无展示与复用界面。
- **基于**：现有 `AiImageService`、图片生成对游客开放（IP 日限 2 次）、`sys_file` 永久化。
- **方向**：登录后画廊按时间/标签浏览自己的产出；提示词模板库（公开 + 个人），一键套用并预填参数；可"克隆"他人/自己的历史生成配置。

### F7 — 文章 / 笔记一键转语音（个人播客）
- **痛点**：已有 `TtsService`（Edge TTS WebSocket），但只能单次合成，无归档与播放。
- **基于**：现有 TTS 能力、`sys_file`、音频文件管理。
- **方向**：笔记/文章"生成语音"→ 存音频 → 个人播客播放列表（前端 audio 列表 + 进度）；支持批量把多篇合成一个合集。

### F8 — 全局 AI 搜索 / 站点 Copilot 浮窗
- **痛点**：内容（笔记/知识库/关于我）分散，跨域检索难。
- **基于**：现有向量检索 + `AiChatService`。
- **方向**：全站统一语义索引（笔记 + 知识库 + 关于我文本）；前端浮窗问答，答案带出处链接；游客受限（IP 限流）。

## 三、个人展示与输出

### F9 — 公开博客 / 文章发布
- **痛点**：关于我页是简历式，缺乏对外输出长文的载体。
- **基于**：现有 `system/profile` 编辑、`/about` 公开页、Markdown 渲染能力。
- **方向**：文章 CRUD（Markdown 编辑器 + 公开阅读页 `/blog`），支持草稿/发布、标签、封面（复用封面工具）；游客可读、作者可管理。与 Memos 形成"短笔记 vs 长文"互补。

### F10 — 实验追踪看板（Lab Notebook）
- **痛点**：定位是"实验沉淀池"，但缺结构化实验记录。
- **基于**：现有数据库 + 仪表盘（`DashboardService`）+ ECharts 前端。
- **方向**：实验记录（目标/参数/过程/结果/对比图），按项目/标签聚合；支持同一实验多 run 对比（类似 ML experiment tracker）；契合"实验沉淀"定位，是最贴定位的功能。

### F11 — 数学游戏成绩趋势 + 分享卡
- **痛点**：成绩存 `sys_game_score` 但仅排行榜，无个人成长可视化与对外分享。
- **基于**：现有 `GameController` 排行榜、成绩表。
- **方向**：个人趋势图（正确率/用时/逐题）、生成可分享的成绩卡（图片，复用图片生成或 canvas）；轻量社交货币。

## 四、工具与效率

### F12 — 技术笔记代码沙箱执行
- **痛点**：开发者个人池，笔记里代码块只能看不能跑。
- **基于**：前端代码高亮（已有）、后端执行能力缺口。
- **方向**：笔记代码块"一键运行"（受限沙箱：Docker/WASM/隔离进程，禁网禁文件写），返回 stdout；适合复现实验脚本。安全是关键，需白名单语言 + 资源限额。

### F13 — 个人 API 网关（开放 AI 能力）
- **痛点**：已有 token 计费（`sys_ai_usage`）与多供应商，但仅服务站内。
- **基于**：现有 `sys_ai_provider`/`sys_ai_model`、Sa-Token、计费体系、IP 限流。
- **方向**：签发个人 API Key（独立密钥，非登录 token），对外暴露 `/v1/chat`、`/v1/image` 等端点，复用现有计费与限流；把自己变成"个人 AI 后端"，供自己其他脚本调用。

## 五、社交 / 分享（保持个人池定位）

### F14 — 分享链接 / 阅后即焚
- **痛点**：想临时把某篇公开页/笔记发给朋友，但无受控分享。
- **基于**：现有游客公开页机制、`sys_file`、Redis（限流/TTL）。
- **方向**：生成带有效期/访问次数上限的分享令牌，可设"阅后即焚"；分享页走游客通道但加令牌校验，不污染正常菜单。

### F15 — 神奇海螺多轮对话 + 占卜史分析
- **痛点**：海螺当前单次问答，无连续对话与模式洞察。
- **基于**：现有 `conch_answer`/`conch_record` 表、`ConchController`。
- **方向**：海螺支持多轮上下文；后台"占卜史分析"看高频主题/情绪走向（复用现有统计图表）；增强可玩性与"沉淀"属性。

## 六、数据与洞察

### F16 — 个人生产力仪表盘
- **痛点**：现有 token 统计只覆盖 AI 消费，缺"时间/精力投入"全景。
- **基于**：现有 `DashboardService`、ECharts、各业务表时间戳。
- **方向**：按项目/标签聚合时间投入（笔记数、AI 调用、游戏时长、实验数）；"本周 vs 上周"产出曲线；把现有监控式仪表盘从"系统视角"扩到"个人产出视角"。

### F17 — PWA 离线 + 移动端随手记
- **痛点**：前端已做移动端适配，但无离线缓存，弱网/地铁无法记。
- **基于**：现有移动端卡片布局（`.note-cards`）、前端栈（Vite/Pinia/UnoCSS）。
- **方向**：加 Service Worker + 离线缓存（笔记草稿本地存 IndexedDB，恢复网络同步）；"添加到主屏幕"；契合"随时随地沉淀"。

### F18 — AI 自动标签 / 智能归档（超越现有打标签）
- **痛点**：现有 Memos AI 打标签是手动触发单条。
- **基于**：现有 `AiMemoryService` 标签写回、`MemosRagService`。
- **方向**：定时批量对未标签/新笔记做 AI 分类 + 智能归档（自动归入项目/主题），并给出"待整理"建议；把手动动作自动化。

## 实施节奏建议

- **近期（低投入高契合，优先做）**：F9 博客、F10 实验看板、F4 内联写作、F11 游戏分享卡、F18 自动归档。
- **中期（AI 产品化主线）**：F5 智能体编排、F6 画廊+提示词库、F7 播客、F8 全局搜索、F1 双向链接。
- **长期（平台化/社交）**：F13 个人 API 网关、F14 分享链接、F12 代码沙箱、F3 多模态记忆、F2 自动摄入、F15/F16/F17。

> 标注依据：所有"基于"项均来自当前代码库（AGENTS.md 模块划分 + 已读源码）。F1/F2/F3/F5/F6/F7/F8 复用现有向量检索与 AI 服务；F9/F10/F11 复用现有前端 ECharts 与公开页机制；F13 复用现有计费/限流/Sa-Token；避免从零造轮子。
